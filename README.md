# Mod Staff Tool (Fabric, 1.21.x)

Клиентский мод-скелет для модераторов сервера. Устанавливается только у
тех игроков, кому вы доверяете (staff), обычным игрокам не выдаётся.

## Функции

| Клавиша | Действие |
|---|---|
| F6 | Freecam вкл/выкл |
| F7 | Staff ESP вкл/выкл (рамки вокруг игроков сквозь стены) |
| F8 | Меню модерации (бан/мут/tp/vanish через GUI) |
| ПКМ по игроку в спектейте | Контекстное меню у курсора (tp/freeze/mute/kick/ban/invsee/copy name) |

Контекстное меню работает только в spectator-режиме (чтобы не ломать обычные
клики по мобам/блокам в выживании) — навёл прицел на игрока, нажал ПКМ,
у курсора появляется меню, как в модах для стаффа на анархиях типа Fantime.

Плюс фоновый логгер: раз в секунду сканирует блоки в радиусе 12 вокруг
игрока и пишет изменения в `.minecraft/modstafftool-logs/block-changes.log`
с указанием ближайшего игрока (эвристика, не 100% доказательство — см. ниже).

## Важно понимать про архитектуру

1. **Это клиентский мод**, `environment: client` в `fabric.mod.json` — на
   dedicated-сервере он не грузится вообще. Игроки без него просто играют
   как обычно.
2. **Кнопки в GUI (F8) и в ПКМ-меню бана/мута/tp/freeze/invsee** — это просто
   обёртка над обычными командами (`/ban`, `/mute`, `/tp`, `/vanish`,
   `/freeze`, `/invsee`). Сервер сам решает, пропускать команду или нет, по
   правам игрока (LuckPerms/группа staff). Команды рассчитаны на
   EssentialsX/CMI-подобный синтаксис — поменяйте строки в
   `ModGuiScreen.java` и `ContextMenuScreen.java`, если у вас другой плагин
   наказаний (freeze и invsee — не ваниль, нужен отдельный плагин типа
   CMI/EssentialsX, иначе команда просто не сработает).
3. **BlockLogger — эвристика.** Клиент технически не может достоверно
   узнать, кто именно сломал блок в мире другого игрока — это знает только
   сервер. Логгер лишь запоминает, кто был ближе всего к месту изменения.
   Для реальных доказательств используйте серверный плагин логирования
   (CoreProtect, Prism и т.п.) — этот лог лишь подсказка "иди проверь тут".
4. **Freecam** в этом скелете отвязывает рендер-камеру и морозит игрока на
   месте, но плавное свободное перемещение камеры (WASD в воздухе без
   отправки пакетов серверу) нужно доделать миксином в обработку ввода —
   в коде оставлен комментарий, где именно.

## Сборка

Нужен установленный JDK 21 и интернет (Gradle подтянет зависимости из
Fabric maven при первой сборке — офлайн собрать этот архив нельзя).

```bash
cd modstafftool
./gradlew build
```

Готовый jar будет в `build/libs/modstafftool-0.1.0.jar`. Кладёте его в
`.minecraft/mods/` вместе с Fabric API (той же версии, что в
`gradle.properties`) и Fabric Loader.

Если `gradlew` нет прав на запуск: `chmod +x gradlew`.
(Gradle wrapper jar в архиве не включён — при первом запуске `gradle
wrapper` в проекте с установленным Gradle 8.8+ его создаст, либо скачайте
`gradle-wrapper.jar` с https://github.com/FabricMC/fabric-example-mod.)

## Структура

```
src/main/java/com/modstaff/tool/
├── ModStaffToolClient.java      — точка входа, регистрация клавиш/событий
└── feature/
    ├── FreecamManager.java      — свободная камера
    ├── EspRenderer.java         — рамки игроков сквозь стены
    ├── PlayerHud.java           — список игроков рядом (ник/дистанция/пинг)
    ├── ModGuiScreen.java        — GUI-меню быстрых команд (F8)
    ├── ContextMenuScreen.java   — ПКМ-меню на игроке в спектейте
    └── BlockLogger.java         — эвристический логгер изменений блоков
```

## Дальнейшие шаги

- Доделать плавное перемещение freecam (миксин на обработку клавиш игрока).
- Подключить фильтр ESP только по нику из вайтлиста staff-команды, если
  нужно скрывать рамки для самих себя друг у друга.
- Заменить строки команд в `ModGuiScreen` под ваш плагин наказаний.
- Когда сделаете сервер — подключить серверный плагин логов (CoreProtect)
  вместо/вместе с клиентским эвристическим логгером.
